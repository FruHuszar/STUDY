# Welcome

## A notebook that reads like a book

These notes are for studying: short chapters, code you can copy, tables you can scan. Search at the top finds words in every note, the colored dots filter by category, and the tags narrow things down further.

## Your own notes stay yours

Sign in with an approved Google account to write private notes. Only you can see them, and the app keeps a copy on your device so you can read them offline.
